Team photo folder
=================

This is the only folder used for team photos on the VA landing page:

`va-site/assets/team/`

Use these lowercase filenames:

- deepanshu.jpg
- amrish.jpeg
- shibu.jpg
- garima.jpeg
- aditi.jpeg
- anjali.jpeg
- anuj.jpeg
- kriti.jpeg
- deeksha.jpeg

Supported formats: .jpg, .jpeg, .png, .webp.

Run `npm run build:va` after changing photos. The builder reads this folder and
replaces matching team avatars with real images in the generated HTML.
